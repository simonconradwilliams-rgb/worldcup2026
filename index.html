What We Built

📅

ICS Calendar File

A complete .ics file containing all 104 World Cup matches with kick-off times (auto-converted to your local timezone), stadium names, and locations.

☁️

Hosted on GitHub Gist

The calendar file is publicly hosted at a permanent URL on GitHub Gist, making it accessible from anywhere at any time.

🔄

Live Google Calendar Subscription

Your Google Calendar subscribes to the Gist URL and polls for updates — meaning when knockout team names are confirmed, your calendar updates automatically.

🔗

Shareable with Anyone

Anyone can subscribe to the same URL and get the same live-updating calendar in their own Google Calendar, Apple Calendar, or any calendar app.

2

Auto-Updates

Knockout Round Updates

How Updates Work

As each knockout round is confirmed, the calendar file on GitHub Gist will be updated with the real team names. Because your Google Calendar is subscribed to the URL (not a one-time import), it will automatically pick up the changes — usually within 24 hours. No action needed on your part. Just ask Claude to update the file after each round!

Maintenance

Updating the Calendar

1

Ask Claude to update the file

After each knockout round, ask Claude to generate an updated .ics file with the confirmed team names.

2

Go to your GitHub Gist

Visit gist.github.com and open your worldcup2026.ics gist.

3

Click Edit (pencil icon)

Select all the existing content and replace it with the new file contents from Claude.

4

Click "Update public gist"

Google Calendar will automatically sync the changes within 24 hours. Anyone subscribed to the URL gets the update too.
